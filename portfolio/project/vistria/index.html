项目介绍

此项目记录我在 Framia 工作期间所负责的UI/X设计，涵盖首页升级改版、Agent Node节点体验链路优化，以及AssetLibrary资产库的全链路设计与搭建，同时承担日常运营视觉素材的设计与产出等等。

02/
THE EXPERT NODE

THE EXPERT NODE

将能力表达模糊的 Agent Node 升级为角色清晰、技能预设的 Expert Node，把趋势研究、视频拆解、脚本规划与创意评审等专业环节融入画布

我设计了 Expert Node 从选择、配置到执行与结果回流的完整流程，以预设技能支持研究、脚本创作、提示词优化和评审

用户只需按任务选择专业角色，即可在统一交互中完成创作，无需重复学习

03/
ASSET LIBRARY

Framia 资产库

将分散在项目与画布中的素材统一管理，覆盖上传导入、文件夹管理、检索预览，以及画布与 Agent Chat 中的调用和回存。

01

初次进入 · 空状态

通过空状态说明资产库的用途，保留添加资产与创建文件夹入口，帮助用户开始建立自己的素材库。

02

本地上传

从 Add 入口上传本地文件，明确呈现拖拽、上传进度与失败反馈，并支持选择或新建保存文件夹。

03

跨项目导入

复用已有项目中的创作素材。按项目与文件类型查找，选中后确认导入当前资产库。

04

创建文件夹

创建文件夹组织素材，完成命名后在资产库中展示，作为后续上传和归档的保存位置。

05

资产浏览

统一展示图片、视频、音频与文件，提供网格和列表两种浏览方式，兼顾视觉查找与信息查看。

06

批量操作

选中多个资产后集中呈现操作栏，支持发送到画布、创建文件夹、下载与删除，并展示新建画布的确认流程。

07

分类筛选

在类型分类之外，按来源、上传时间和创建者组合筛选，保留已选条件，缩小查找范围。

08

搜索查找

通过关键词寻找素材，展示搜索建议、匹配内容与无结果反馈，再进入结果列表继续操作。

09

单个资产管理

通过单个资产的操作菜单完成移动、发送到画布、重命名、预览、下载和删除；需要输入时以弹窗承接。

10

资产包创建与管理

围绕文件夹管理成组素材，提供资产包操作菜单和全部文件夹视图，支持集中整理与查找。

11

资产包预览

打开资产包时以侧边抽屉查看内部内容，在保留原页面上下文的同时继续搜索、筛选和浏览素材。

12

多类型资产预览

为图片、视频、演示文稿和文档提供对应预览方式，结合资产信息与页面导航，支持查看和后续使用。

13

画布侧栏调用

在创作画布中打开资产库侧栏，完成浏览、搜索、批量选择和发送到画布；同时保留加载与空状态。

14

Agent Chat 上传与调用

在 Agent Chat 中选择本地上传或资产库素材，查看文件夹、操作单个资产并确认添加，使素材进入当前对话任务。

15

画布成果保存

从画布中保存单个生成结果或整组内容，选择素材和目标文件夹，完成保存后给出成功反馈。
